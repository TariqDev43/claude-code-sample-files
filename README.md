# Claude Code sample files

Two small, plain-text files you can copy and edit. Free, MIT licensed.

| File | What it is |
|---|---|
| `CLAUDE.md.sample` | A starting `CLAUDE.md` for any project: commands, layout, rules, definition of done. Rename to `CLAUDE.md` and fill the `<placeholders>`. |
| `ai-extension-safety-checklist.md` | A 1-page checklist for vetting an AI coding extension before you install it. |

## Honest labels
Both files are new, written from habits we use ourselves (branch first, never commit secrets, ask before risky actions, say what was not checked). They are starting points, not guarantees. Edit them for your project.
